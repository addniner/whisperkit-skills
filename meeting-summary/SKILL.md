# 회의 전사본 요약

완성된 전사본을 읽고 주요 논의, 결정 사항, 액션 아이템을 근거 중심으로 정리한다. STT나 미디어 변환은 수행하지 않는다.

## 책임 경계

- 입력: `transcript.txt` 또는 사용자가 제공한 회의 전사 텍스트
- 출력: 전사본과 같은 폴더의 `summary.md`
- 하지 않는 일: 미디어 디코딩, STT, 화자 분리, 전사본 수정
- 입력이 오디오·영상뿐이면 `whisperkit` 스킬을 먼저 사용한다.

## 입력 처리

1. 사용자가 지정한 전사본을 우선 사용한다.
2. 녹음 결과 폴더를 지정했다면 그 안의 `transcript.txt`를 사용한다.
3. 텍스트가 대화에 직접 제공되었다면 결과를 Markdown으로 응답하고, 파일 저장을 요청한 경우에만 `summary.md`를 생성한다.
4. 전사본이 없고 미디어만 있다면 `whisperkit` 스킬로 전사한 뒤 계속한다.
5. 긴 전사본도 일부만 읽고 요약하지 않는다. 전체 내용을 확인하고 중복 논의를 합친다.

## 작성 원칙

- 전사본에 근거가 없는 이름, 역할, 결정, 담당자, 기한을 만들지 않는다.
- 제안·검토·가정을 확정된 결정 사항과 구분한다.
- 명시되지 않은 담당자나 기한은 `미정`으로 표시한다.
- 화자 이름을 알 수 없으면 `화자 A` 같은 원래 라벨을 유지한다.
- 역할은 충분한 근거가 있을 때만 `추정`이라고 명시해 기록한다.
- 타임스탬프가 있으면 안건 구간과 중요한 결정에 활용한다.
- 민감하거나 사적인 발언은 업무상 필요한 수준으로만 요약한다.
- 기존 `transcript.txt`와 원본 미디어는 수정하지 않는다.

## 출력 형식

```markdown
# 회의 요약

- **일시:** YYYY-MM-DD 또는 미상
- **참석자:** 화자 A, 화자 B

## 한눈에 보기

- 회의 목적과 핵심 결과를 2~4개 항목으로 요약

## 주요 안건

### 1. 안건명 (HH:MM:SS~HH:MM:SS)

- 논의 내용
- 결론 또는 현재 상태

## 결정 사항

| 결정 | 근거 시점 |
|------|-----------|
| ... | HH:MM:SS |

## 액션 아이템

| 담당 | 할 일 | 기한 | 근거 시점 |
|------|-------|------|-----------|
| 화자 A | ... | 미정 | HH:MM:SS |

## 미해결 사항

- 추가 확인이나 후속 논의가 필요한 내용
```

타임스탬프가 없는 입력에서는 관련 열과 안건 시간 범위를 생략한다. 결정 사항이나 액션 아이템이 없으면 `확인된 항목 없음`이라고 적고 섹션을 유지한다.

## 저장 규칙

파일 기반 전사본은 같은 녹음 폴더에 저장한다.

```text
rec_2026-03-30_001/
├── audio.mov
├── transcript.txt
├── summary.md
└── data/
```

기존 `summary.md`가 있으면 사용자 확인 없이 덮어쓰지 않는다. 새 버전을 원하는 경우 `summary-v2.md`처럼 별도 파일을 제안한다.

## 품질 확인

저장 전에 다음을 점검한다.

- 모든 결정 사항이 전사본에서 확인되는가?
- 제안이 결정으로 잘못 표현되지 않았는가?
- 액션 아이템의 담당자와 기한이 근거 없이 채워지지 않았는가?
- 중요한 반대 의견이나 미해결 문제가 누락되지 않았는가?
- 화자 라벨과 타임스탬프가 원문과 일치하는가?
